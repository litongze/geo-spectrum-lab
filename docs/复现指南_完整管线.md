## 第一步:训练模型池(约 2-3 小时,可并行)

```bash
B="model.n_freq_basis=16 model.n_vis_rank=16 model.scatter_dropout=0.1 \
   train.epochs=180 train.batch_size=64 train.device=cuda"

# 主力配方(graft): seed0 + split_seed=0
python3 scripts/train.py --config configs/round1_scatter.yaml --set $B \
  train.seed=0 train.split_seed=0 output.ckpt=checkpoints/round1_graft.pt

# 种子多样性成员 es1-3(同配方, seed 1-3, split_seed=0)
for s in 1 2 3; do python3 scripts/train.py --config configs/round1_scatter.yaml \
  --set $B train.seed=$s train.split_seed=0 output.ckpt=checkpoints/es$s.pt; done

# 数据子集bagging bag1-8(split_seed 1-8, 各自val选epoch)
for k in 1 2 3 4 5 6 7 8; do python3 scripts/train.py --config configs/round1_scatter.yaml \
  --set $B train.seed=$((10+k)) train.split_seed=$k output.ckpt=checkpoints/bag$k.pt; done

# 损失多样成员
python3 scripts/train.py --config configs/round1_scatter.yaml --set $B \
  train.lambda_pas=2.0 train.lambda_pdp=0.5 train.split_seed=0 output.ckpt=checkpoints/div_pas.pt
python3 scripts/train.py --config configs/round1_scatter.yaml --set $B \
  train.lambda_pas=0.5 train.lambda_pdp=2.0 train.split_seed=0 output.ckpt=checkpoints/div_pdp.pt

# 结构多样成员(可选但有贡献): 地图特征/大散射体
python3 scripts/train.py --config configs/round1_scatter.yaml --set $B \
  data.use_map_features=true train.split_seed=0 output.ckpt=checkpoints/base_map.pt
python3 scripts/train.py --config configs/round1_scatter.yaml --set $B \
  model.n_scatterers=8192 train.split_seed=0 output.ckpt=checkpoints/big1.pt
```

## 第二步:eps 截断度量微调(最大单项增益,线上+0.009)

```bash
# 从graft微调出 epscap(eps=1e-9) 与 epscap35(eps=3.5e-9)
python3 scripts/finetune_epscap.py --init checkpoints/round1_graft.pt \
  --datadir "Round1_Map(2)" --out checkpoints/epscap.pt --epochs 70 --lr 2e-4 --no-c3 --eps 1e-9
python3 scripts/finetune_epscap.py --init checkpoints/round1_graft.pt \
  --datadir "Round1_Map(2)" --out checkpoints/epscap35.pt --epochs 70 --lr 2e-4 --no-c3 --eps 3.5e-9
# 顶级成员也微调一版入池(bag5微调后solo最强0.428)
for m in es1 gswa bag5 gwd; do python3 scripts/finetune_epscap.py --init checkpoints/$m.pt \
  --datadir "Round1_Map(2)" --out checkpoints/${m}_e35.pt --epochs 50 --lr 2e-4 --no-c3 --eps 3.5e-9; done
```
注意:`epscap.pt` 是最终管线的 **GS 相位参考**,必须存在。

## 关键常数(实测校准,勿改)
- 提交操作点:全局RMS 4e-6 → PAS/PDP 切片抬底 4.28e-9(> 真实eps≈3.5e-9)
- blend α≈0.5(池权重),kNN臂 k=3~16 IDW²/注意力
- val 协议:臂的邻居必须用**全2000点留自身**(=test真实条件),否则系统性低估
