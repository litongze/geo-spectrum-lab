# Teammate Transformer Source

This directory is a source-only snapshot of the Transformer implementation
provided by the teammate on 2026-07-30.

- It is kept separate from the root `wireless_twin/` package.
- The GS37 geometric-phase search does not import this package implicitly.
- Checkpoints, cached arrays, predictions, and competition data are not stored
  here or committed to Git.

Run scripts in this directory with `code/` as the project root when reproducing
the teammate Transformer.
